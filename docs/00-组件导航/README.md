# 组件导航层

这一层是**"快速理解代码库"的入口**：每个核心目录一篇导航表，回答三个问题——
①这目录里每个文件**管什么** ②**关键入口/字段**在哪 ③细节**看哪篇专题**。

**三层文档分工：**

| 层 | 位置 | 问什么 |
|----|------|--------|
| 心智地图 | `CLAUDE.md` | 数据流长什么样？各子系统怎么呼应？有哪些坑？ |
| **组件导航**（本层） | `docs/00-组件导航/` | 这个组件/文件在哪？管什么？入口在哪？ |
| 专题/入档 | `docs/01`–`docs/08` | 某机制为什么这么设计？权威口径？精灵表现追溯？ |

**规则：代码是唯一权威。** 本层只做"导航不做重述"——列入口、不抄实现。
若代码与文档相悖，以代码为准；发现本文过时，就地更新这一行，别写进正文。

1. `CLAUDE.md` 全文（架构地图，含数据流 + 所有坑）。
